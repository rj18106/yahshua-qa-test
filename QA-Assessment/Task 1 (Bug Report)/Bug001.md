# Bug 001 (Maximum advance date range for the newly added employee's date hired)

## Description
When adding a new employee, the Date Hired input field does not restrict or limit future dates, allowing users to successfully save an advanced hiring date such as 2027.

## Severity
Low

## Steps to Reproduce
1. Access the PH Payroll Calculator
2. Access the Employees screen by clicking the Employees in the navbar
3. Click the "+Add Employee" button
4. Input the First Name
5. Input the Last Name
6. Input the Email
7. Input the Position
8. Input the Department
9. Select Employment Type
10. Input Monthly Salary
11. Select Date Hired (September 01, 2027)
12. Click "Add Employee" button

## Expected Result
A Prompt message should display that restrict or limit future dates

## Actual Result
Adding the employee was saved successfully
